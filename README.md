Aplicativo desenvolvido em React Native com Expo que permite:

- adicionar itens à lista de compras;
- visualizar itens cadastrados;
- marcar itens como comprados;
- excluir itens;
- salvar os dados localmente utilizando AsyncStorage.


- React Native
- Expo
- TypeScript
- AsyncStorage


1. Instale as dependências:

```bash
npm install
```

```bash
npx expo install @react-native-async-storage/async-storage
```

2. Execute o projeto:

```bash
npx expo start
```

3. Abra no celular usando o aplicativo Expo Go ou em um emulador.
